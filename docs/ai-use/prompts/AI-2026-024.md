## Exact human-authored prompt

modify the v3 inv tool such that it will automatically interpret the functions rather than spitting them into a 30k line file.

Final architecture should look like src/v3/cpp_inventory/
    cli.py
    config.py
    schema.py
    runner.py
    normalize.py
    scope.py
    dedup.py
    coverage.py
    report.py

Responsibilities:

config.py: load project and [scope] include/exclude rules from TOML.
schema.py: define raw/normalized function record structures and serialization helpers.
runner.py: read compile_commands.json as the authoritative TU list and invoke clang_inventory once per TU using --source-file. Support selecting TUs under an optional source directory, but do not discover TUs by recursively scanning for .cpp files. Collect successful JSONL and record exact TU failures.
normalize.py: convert source file and translation-unit paths to stable repo-relative paths. Do not perform filtering.
scope.py: apply only TOML include/exclude patterns. Do not hardcode test, benchmark, vendor, or generated-file rules. Record exclusions and reasons.
dedup.py: deduplicate across TUs using non-empty Clang USR as primary identity. Fallback identity should be normalized file + start offset + qualified name + kind. Preserve useful provenance such as observation count / translation units where practical.
denominator policy: source template definitions count once; implicit template instantiations are excluded from the primary denominator; lambdas are retained but excluded from the primary denominator; explicit specializations should remain visible as a separate auditable category.
coverage.py: calculate TU coverage and all reduction counts.
report.py: generate machine-readable summaries and a concise Markdown report.
cli.py: orchestrate the full pipeline.
